Cajero Automático de la empresa BANCONAC - Consola C#

Simulación realista de cajero automático, creada por la empresa fictica de BANCONAC, otorgando una versión mejorada con protocolos de seguridad, funcionalidad
y eficacia, mostrando diferentes opciones para elegir y poder completar procesos como en la vida real.

🚀 Características
- ✅ Datos se guardan automáticamente en formato de archivo tipo JSON para futuros almacenamientos en bases de datos.
- ✅ Registro de PIN para acceder al sistema del cajero automáico.
- ✅ Menú con múltiples opciones.
- ✅ Registro de cuenta bancaria para realizar depósitos, retiros, transferencias, etc.
- ✅ Verifica lineamientos de seguridad (Ingresar texto en línea de números, exceder un valor permitido, ingresar un carácter incorrecto, ingresar
un símbolo).
- ✅ Creación de clases abstractas para controlar cálculos complejos.
- ✅ Creación de métodos que realizar procesos complejos según la opción elegida por el usuario.
  

🛠️ Tecnologías
Lenguaje: C#
Plataforma: .NET (cualquier versión que soporte consola)
Compilador: dotnet, Visual Studio, o csc.
📦 Requisitos previos

Tener instalado:

.NET SDK (recomendado 6.0 o superior)
O Visual Studio Community
O Visual Studio Code con extensión C#
⁉️ ¿Cómo encontrar la carpeta donde se aloja el código?

En carpeta llamada "Cajero_Automatico-BANCONAC" deslizas hacia abajo.
El archivo llamado "Program.cs" das doble click y aparece el código.

▶️ Cómo ejecutar

Opción 1: Con Visual Studio (más sencillo)

Crea un nuevo proyecto de Aplicación de consola (.NET).
Copia todo el código en el archivo Program.cs.
Compila y ejecuta con F5 o el botón Iniciar (▶️).

Opción 2: Con Visual Studio Code / terminal
Clona o descarga este repositorio.
Abre una terminal en la carpeta donde está el archivo Program.cs.

Crea un proyecto de consola (solo la primera vez):
dotnet new console
